# AI for Science — Tech Labs 2026

Course website, served with GitHub Pages at https://danturner-evans.github.io/AI-for-science/

- `index.md` — overview, slides, readings
- `_data/readings.yml` — reading list (edit here to add/remove readings)
- `lab/` — the in-class VIPR/CRISPR exercise (student version): `index.md` is the landing page, one file per part
- `_data/lab.yml` — order, titles and times of the lab pages (drives the cards and prev/next links)
- `_config.yml` — site settings, including the Figma slide links
